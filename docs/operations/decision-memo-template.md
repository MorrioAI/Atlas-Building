# Operations — Decision Memo Template

For any decision that's expensive, hard to reverse, or affects other people's work.

## Decision
State it in one sentence, up front.

## Context
What's forcing a decision now?

## Options
For each: the option, its cost, and what would have to be true for it to be right.

## Recommendation
Which option, and why. Name the tradeoff you're accepting.

## Reversibility
Is this a one-way or two-way door? Two-way doors get decided fast.

## Owner & date
Who decides, by when.

> Price the outcome, not the feature set. What is this worth to the person on the other side?
