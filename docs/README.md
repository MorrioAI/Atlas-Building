# The Atlas Handbook

How we work at Atlas. Short, opinionated, and enforced in review. Read the section for your craft before you contribute.

- **[Engineering](./engineering)** — coding standards, code review, testing, git workflow, [verification](./engineering/verification.md), [error reporting](./engineering/error-reporting.md)
- **[Product](./product)** — spec template, RFC process
- **[Design](./design)** — design doc template, design system
- **[Data](./data)** — metrics standards, SQL style
- **[Marketing](./marketing)** — brand & voice
- **[Operations](./operations)** — decision memos, [cost controls](./operations/cost-controls.md)
- **[Architecture Decision Records](./adr)** — why the system is the way it is

> These are our conventions for contributing to the real product. If you're here to **learn** the craft with guided missions and feedback, that experience lives on [Morrio Universe](https://morrio.ai/universe).
